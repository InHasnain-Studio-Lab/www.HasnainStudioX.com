How to fix the most common Windows problems yourself

A stuck print queue, a network that will not connect, an update that never finishes, and damaged system files: the repairs that work, in the order to try them.

By Hasnain, founder and developer · 10 November 2026

Most of the faults that make people think their PC needs a reinstall are much smaller than they look. A printer that will not print, a network that drops, an update that fails every night: each has a standard repair that Windows already includes. The skill is knowing which one to reach for, and in what order.

Before you touch anything

Two minutes of preparation saves a lot of worry.

  • Restart properly. Choose Restart, not Shut down. A shut down PC with fast startup turned on does not fully reload Windows, so a restart clears faults that switching off and on again does not.
  • Make a restore point. Search the Start menu for Create a restore point, select your Windows drive and choose Create. If a repair makes things worse, you can step back.
  • Write down the exact message. An error code searched word for word finds the answer far more often than a description of the symptom.

The print queue that will not clear

A document gets stuck, everything behind it waits, and cancelling does nothing. The queue is held by a Windows service called the Print Spooler, and the cure is to stop it, empty its folder and start it again.

  1. Search the Start menu for Services and open it.
  2. Find Print Spooler, right click it and choose Stop.
  3. Open File Explorer, go to C:\Windows\System32\spool\PRINTERS and delete everything inside. Windows will ask for permission. Delete only the contents, not the folder.
  4. Back in Services, right click Print Spooler and choose Start, then print again.

The network that will not connect

Work from the simplest cause to the deepest. First, check whether other devices on the same network are online. If they are not, the problem is the router or your provider, and restarting the router is the right first step. If only your PC is affected, try these in order and test after each one:

  1. Turn Wi-Fi off and on, or unplug and replug the network cable.
  2. Forget the Wi-Fi network in Settings and join it again with the password.
  3. Open Command Prompt as administrator and run ipconfig /flushdns. It clears the list of web addresses Windows remembers, which fixes sites that load everywhere except your PC.
  4. If that fails, run netsh winsock reset and netsh int ip reset, then restart.
  5. As a last step, use Network reset in Settings, Network and internet, Advanced network settings. It reinstalls every network adapter, so you will need your Wi-Fi password again afterwards.

The update that fails every time

When Windows Update fails over and over with the same code, the downloaded files are often damaged, and Windows keeps retrying the broken copy. Clearing them makes it download fresh ones.

  1. Open Services and stop Windows Update and Background Intelligent Transfer Service.
  2. Open C:\Windows\SoftwareDistribution and delete the contents of the Download folder inside it.
  3. Start both services again and check for updates.

If an update still fails, search for its KB number with the word failed. Sometimes the fix is simply waiting for Microsoft to replace a faulty update, and that is worth knowing before you spend an evening on it.

When Windows itself is damaged

Odd crashes, settings pages that will not open and features that stop working can point to damaged system files. Windows can check and repair its own files with two commands. Run them in Command Prompt as administrator, in this order:

  1. DISM /Online /Cleanup-Image /RestoreHealth repairs the store Windows uses as its reference copy. It can take a while and may pause at a percentage. Let it finish.
  2. sfc /scannow then compares your system files against that copy and replaces any that are damaged.
  3. Restart when both have finished.

What not to do

Skip registry cleaners. Removing leftover registry entries does not make Windows faster, and a wrong deletion can stop an app or Windows feature from working. Be wary of long lists of services to disable. Most save nothing you would notice and break something you will. Do not run repair tools you downloaded from an advert. If a site is warning you your PC is infected, close it.

Quick reference

ProblemFirst thing to try
Printing stuckStop Print Spooler, empty the PRINTERS folder, start it again
One website will not loadFlush the DNS cache with ipconfig /flushdns
No internet on this PC onlyForget and rejoin the network, then the winsock and IP resets
Update fails with the same codeClear the SoftwareDistribution Download folder
Random crashes and broken settingsDISM RestoreHealth, then sfc /scannow
Everything got worse after a changeGo back to the restore point you made first

The short version: restart properly, make a restore point, and work from the smallest repair to the biggest. Most faults are fixed long before a reinstall would have been, and every step here is one Windows already provides.
