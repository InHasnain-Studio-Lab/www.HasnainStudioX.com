Your first hour with a new PC

Five things worth doing before anything else. Each step works with Windows' own tools; where one of our apps helps, it is named.

  1. Bring Windows up to date

    Open Settings, then Windows Update, and install until nothing is left. A new PC has often sat in a box for months.

  2. Make a recovery drive

    A USB stick that can start the PC when Windows will not. Use Windows' Recovery Drive tool, or build boot media with HSX BootForge.

  3. Go through your privacy settings

    Settings, then Privacy and security, controls what Windows and your apps can see. PC GuardX gathers those controls into one dashboard.

  4. Set up a backup before you need one

    OneDrive or File History cover the basics. HSX FileGuardian Ultra keeps version history of the folders you choose, offline.

  5. Install from sources you can trust

    Apps on the Microsoft Store go through Microsoft's certification before they are listed. Every Hasnain Studio X Windows app is sold only there.
