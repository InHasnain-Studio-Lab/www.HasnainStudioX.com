Hasnain Studio X

Hasnain Studio X is an independent software studio based in England, United Kingdom, founded by Hasnain Butt Akhtar (online as InHasnain).

We publish desktop and mobile software to a single engineering standard: computation happens on the user's device, data stays there, and no product requires an account to function. 63 applications are live across the Microsoft Store and Google Play, each with its own published privacy policy and a free trial.

The standard is deliberately narrow, and it does not change per release.
