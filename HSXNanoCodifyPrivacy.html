Privacy Policy

HSX NanoCodify is developed by Hasnain Studio X with a local‑first, privacy‑first design philosophy. It edits the folder you open on your own PC and talks only to the model service you point it at.

Effective date: 16 August 2026  ·  Publisher: Hasnain Studio X  ·  Developer: Hasnain Butt Akhtar  ·  Applies to: HSX NanoCodify (Windows App), version 1.0.0.0

1. Overview

HSX NanoCodify is developed by Hasnain Studio X with a local-first, privacy-first design philosophy.

  • We do not collect personal data.
  • We do not transmit any data to external servers.
  • We do not operate servers for our apps.
  • We do not sell, share, or monetize user data.

All editing and all assistant work happens on your own device, against a model service whose address you choose.

2. Data We Do NOT Collect

HSX NanoCodify does not collect, store, or send any of the following:

Personal Identity Data

No name, email, phone number, address, or identifiers.

Usage Data or Analytics

No telemetry, crash analytics, tracking, or advertising SDKs.

Your Source Code and Prompts

No source files, file names, folder paths, prompts, assistant replies, command output, or commit messages are ever sent to us.

Sensitive System Data

No passwords, tokens, credentials, browsing history, or system logs.

Location Data

No GPS, IP-based location, or device location.

We do not run servers, so nothing can be uploaded to us even by accident.

3. Data Stored Locally on Your Device

App Settings

Your chosen mode, accent theme, model service address, permission rules, editor preferences and panel sizes are saved locally on your device only.

Sessions and Activity Record

Each saved conversation and the line-by-line record of every tool call and file change are written to your local app data folder as plain JSON files you can read or delete yourself.

Your Extensions

Agent definitions, instruction packs, slash commands, hooks and automation triggers are plain Markdown and JSON files in the same folder.

Local Trial or Licence State

Managed entirely by the Microsoft Store. The app reads it locally; we receive nothing.

This data never leaves your device unless you explicitly export it.

4. Microsoft Store Licensing

HSX NanoCodify is sold through the Microsoft Store with a free trial. All licensing, payments, and transactions are handled exclusively by Microsoft.

  • We do not process payment information.
  • We do not store payment details.
  • We do not receive your Microsoft account information.

5. App Permissions

Minimum Required Only

HSX NanoCodify requests only the minimum permissions required for core functionality. Permissions are used solely for app features and never for data collection.

File Access

Only the folder you open. While the workspace sandbox setting is on, any read, write or search that resolves outside that folder is refused before it runs. Exports are written only where you choose.

On-Device Processing

Editing, searching, diffing, source control and the assistant loop all run on your own machine. Nothing is sent to us to be analysed and nothing is downloaded while you work.

Running Commands

The assistant can run shell commands only after you approve them, and every call is recorded in the local activity log.

6. Network and Third Party Services

Every outbound connection HSX NanoCodify can make is listed here.

On-device model

The assistant, the document search and the picture generator all run on this PC. Your prompts, your files and anything you create are processed locally and are not sent anywhere.

Optional extra models you choose to download

The app ships with everything it needs and never downloads on its own. If you choose to add another model from Settings, the app contacts the public model registry to fetch it. Only the model name you typed is sent. Nothing about you, your files or your prompts is included, and you can skip this entirely.

Microsoft Store licence check

Used to read the trial or purchase state at launch. No file content, file name, or usage information is transmitted.

Web fetch tool

Off by default. While it is off, the tool is not offered to the model at all. If you switch it on in Settings, the assistant can request a web address you or it names, and that request reaches that site directly.

External tool servers

You may connect external tool provider programs. They run as child processes on this PC under your account, and anything they send or receive is governed by that program and its own policy, not by us.

7. Children's Privacy

HSX NanoCodify is a general-purpose developer and productivity tool. It is not directed to children under 13 and does not collect any data from any user.

8. Policy Updates

If this policy changes, we will update the version and effective date. Any changes will remain consistent with our core principle: Your data stays on your device.
