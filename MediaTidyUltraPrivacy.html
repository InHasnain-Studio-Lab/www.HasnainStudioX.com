Privacy Policy

MediaTidy Ultra is developed by Hasnain Studio X with a local‑first, privacy‑first design philosophy.

Effective date: 1 August 2026  ·  Publisher: Hasnain Butt Akhtar / Hasnain Studio X  ·  Applies to: MediaTidy Ultra (Windows App)

1. Overview

MediaTidy Ultra is developed by Hasnain Studio X with a local-first, privacy-first design philosophy.

  • We do not collect personal data.
  • We do not transmit any data to external servers.
  • We do not operate servers for our apps.
  • We do not sell, share, or monetize user data.

All processing happens locally on your device.

2. Data We Do NOT Collect

MediaTidy Ultra does not collect, store, or send any of the following:

Personal Identity Data

No name, email, phone number, address, or identifiers.

Usage Data or Analytics

No telemetry, crash analytics, tracking, or advertising SDKs.

Your Photos, Video And Files

No photos, videos, thumbnails, file names, or folder paths. Your pictures are read on this PC and are never transmitted.

Sensitive System Data

No passwords, tokens, credentials, browsing history, or system logs.

Location Data

No GPS, IP-based location, or device location.

We do not run servers, so nothing can be uploaded even by accident.

Advertisement Ad space reserved — activates once AdSense review completes

3. Data Stored Locally on Your Device

App Settings

Your chosen folders, detector choices, thresholds and appearance are saved in a settings file on this PC only.

Library Index

So a repeat scan is fast, the app remembers what it measured about each file: its path, size, dates, camera name and a set of numbers describing how the picture looks. This index stays on this PC and can be cleared from the Dashboard at any time.

Session Log, Quarantine And Compression Originals

Every removal writes a log of which files were moved and where, so you can put them back later. In quarantine mode the files themselves are moved into a folder on this PC instead of the Recycle Bin. When you compress media, the original file is moved into that same local session store before its smaller replacement is written, so the run can be undone. All of it stays on this PC and you can delete it at any time.

Local Trial or Licence State

Managed entirely by the Microsoft Store. The app reads it locally; we receive nothing.

This data never leaves your device unless you explicitly export it.

4. Microsoft Store Licensing

MediaTidy Ultra is a paid app with a free trial managed by the Microsoft Store. All licensing, payments, and transactions are handled exclusively by Microsoft.

  • We do not process payment information.
  • We do not store payment details.
  • We do not receive your Microsoft account information.

5. App Permissions

Minimum Required Only

MediaTidy Ultra requests only two package capabilities: internet client, and run full trust so it can work with your files as a normal desktop program. Neither is used for data collection.

File Access

Only when you choose a file — never background scanning.

On-Device Processing

Duplicate matching, scene matching, sharpness and exposure measurement all run on this PC using files bundled with the app. Photo and video compression also runs entirely on this PC, using the encoder built into Windows. Nothing is uploaded for processing.

Network Access

Used only for the Microsoft Store licence check. The app has no other online feature and sends us nothing.

6. Children's Privacy

MediaTidy Ultra is a general-purpose utility. It is not directed to children under 13 and does not collect any data from any user.

7. Policy Updates

If this policy changes, we will update the version and effective date. Any changes will remain consistent with our core principle: Your data stays on your device.
